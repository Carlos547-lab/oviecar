Política de Privacidad - Oviecar

Última actualización: Septiembre 2026

1. Información que recopilamos

Oviecar no almacena datos personales de los usuarios. Solo utilizamos los permisos de TikTok necesarios para publicar contenido en nombre del usuario autorizado.

2. Uso de la información

La información obtenida a través de la API de TikTok se usa exclusivamente para completar el proceso de publicación autorizado.

3. Compartir información

No compartimos, vendemos ni transferimos datos personales a terceros.

4. Seguridad

Los tokens de acceso se almacenan de forma segura y se eliminan cuando el usuario revoca la autorización.

5. Contacto

Para consultas: oviedocarlos_emprende@tiktok.com
